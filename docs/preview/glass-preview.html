材质配方（ArkTS 与 CSS 同源）

参数ThinRegularThick作用
radius162434模糊半径，决定「厚度」
saturation1.61.82.0饱和度增益，>1 背景才透色；等于 1 就是灰蒙蒙的磨砂
brightness1.041.050.82亮度增益；厚面板要压暗才保证文字可读
染色 alpha深色 0.50 / 厚 0.70；浅色 0.65 / 厚 0.85染色必须带透明度，否则模糊被实色盖死
折射亮边1px 描边 + 顶部高光条（两端淡出）缺这层就是「磨砂塑料」，不像玻璃
弥散投影radius 14 / 22 / 30，offsetY 5 / 8 / 12让组件从背景浮起来，不是贴上去
按压反馈scale 0.96 + brightness +0.05（按下提亮）「指尖打光」——按下时按钮自己变亮
