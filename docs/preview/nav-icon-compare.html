用工程里 真实的 4 个 ic_nav_*.svg 按 1vp = 1px 渲染，背后铺海报色块以还原玻璃状态。 「小」不只是容器数字小：SVG 图形只占 viewBox 约 68%，叠加 1.8 的细描边和 0.58 的未选中透明度，四个里三个都发虚。

项改前改后（已落地）为什么
NavIcon 尺寸硬编码 23vpMetrics.floatNavIcon = 27vptoken 原先定义了 22 却从未被引用；现改为唯一来源，两处导航共用
SVG 描边stroke-width 1.82.1（base + dark 共 8 个文件）1.8/24×23 ≈ 1.7vp，3.5 倍屏下只有 6px，视觉发虚
未选中透明度0.580.72保留主次对比，但不再让 3/4 图标「退到背景里」
单项高 / 胶囊 padding45 / 348 / 248 + 2×2 = 52，仍等于 Metrics.floatNavHeight，底部留白计算不变
图标与文字间距Column space 2Column space 3图标放大 4vp 后 2vp 会显得压字，补 1vp 呼吸感
viewBox0 0 24 24不变收紧 viewBox 能再放大约 14%，但 ArkUI 的 SVG 解析器对非零 min-x 未经真机验证，本轮不上（见 C 档演示）
