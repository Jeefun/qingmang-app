这是「看得见」的虚拟预览，不是模拟器

先说结论：这台机器上 DevEco 模拟器跑不起来。
实测 HypervisorPresent=False（Hyper-V 未启用），而 HarmonyOS 模拟器必须依赖它； 同时模拟器镜像一个都没下载（imageList 全是 downloaded:false，最新是 HarmonyOS 7.0.0(26.0.0)，与你工程的 API 26 对得上），协议也还没同意。 启用 Hyper-V 要管理员权限 + 重启一次，我这边做不了。

所以下面这份是按源码参数复刻的 HTML 预览：尺寸取自 Theme.ets（1260px / 360vp，比例 3.5）， 控件高度、视频区 58% 屏高、弹幕 8.2s 穿屏、轨道行高 24vp 都照抄 PlayerView.ets 的常量， 颜色取自 color.json。用来核对「有没有、在不在、挤不挤」，够用； 但字体度量、真实画面比例回填、系统手势这些，仍要真机。

可以直接点的东西
齿轮（顶栏/底栏都行）→ 面板滑入；弹幕图标 → 收/开弹幕；中央大按钮 → 暂停（弹幕会跟着停）；全屏键 → 切换形态。
重点看这三处
1. 全屏顶栏现在有齿轮了（原来完全没有设置入口）。
2. 弹幕在 9:16 竖屏片源上只占画面上部 55%，不压字幕区。
3. 面板限高 404vp 可滚，字号/区域/不透明度都在里面，不用再翻小菜单。
